# Politique de Confidentialité - IzyPower Titan Buddy

Dernière mise à jour : 9 août 2026

Cette politique de confidentialité décrit comment l'application **IzyPower Titan Buddy** gère vos données.

## 1. Souveraineté des Données
L'application est conçue pour fonctionner principalement en mode local. Vos données de puissance, de batterie et de production solaire sont récupérées directement depuis vos appareils sur votre réseau Wi-Fi local et ne sont pas transmises à des serveurs tiers, sauf action explicite de votre part (intégration Cloud optionnelle).

## 2. Permissions Utilisées
L'application demande les permissions suivantes pour son bon fonctionnement :

*   **Localisation (ACCESS_FINE_LOCATION)** : Requis par Android pour effectuer des scans Bluetooth (BLE) afin de configurer vos micro-onduleurs. L'application ne suit pas vos déplacements et ne stocke pas votre position géographique.
*   **Bluetooth** : Utilisé pour la communication et le provisionnement des appareils IzyPower.
*   **Réseau / Wi-Fi** : Requis pour communiquer avec les batteries Titan et les onduleurs sur votre réseau local.
*   **Notifications** : Utilisé pour vous alerter en cas de batterie faible ou de surchauffe (si configuré).
*   **Service d'Arrière-plan** : Requis pour maintenir la surveillance de vos appareils et mettre à jour les widgets.

## 3. Collecte de Données Personnelles
*   **Identifiants Cloud** : Si vous utilisez l'intégration optionnelle Solarman Deye Cloud pour les mises à jour des données, votre e-mail et mot de passe sont stockés localement sur votre appareil de manière sécurisée. Ils sont transmis uniquement au serveur officiel `vaysunic.com` pour authentification.
*   **Données Tiers** : Nous n'utilisons aucun outil d'analyse tiers (Google Analytics, Firebase, etc.) et nous ne diffusons aucune publicité.

## 4. Partage de Données
Nous ne vendons, n'échangeons, ni ne transférons vos informations à des tiers.

## 5. Contact
Pour toute question concernant cette politique, vous pouvez contacter le développeur via le dépôt GitHub officiel : https://github.com/MarcoCMG/titan-buddy-connect
